    3 Run the checks

    Two passes fill in most of the assessment before you touch it: the live sources this tool can query itself, then an AI assistant for everything else.

    1. Auto-check the live sources Queries every source with a public data API (Atlas of Living Australia, WildNet…) straight from your browser.

    2. Copy the prompt into an AI assistant A complete, self-contained prompt for this site — paste it into ChatGPT, Gemini, Claude or Copilot and let it research everything else.

    3. Paste its reply back here The assistant answers with one JSON object. Paste the whole reply — code fences and stray commentary are fine. Anything it left blank keeps the result you already have.

    4 Finish & include each source

    How to work through the list
    1. Start with what still needs you. Needs you in the collection bar above shows only the sources nobody has answered yet (Manual / Failed / Not checked). The rail on the far left carries the same count per category.
    2. Read what came back, then answer it. Each card leads with the source's own words; put what you make of it in Your note, and set a Result — Found Nothing found Search failed Needs manual check. Open the source ↗ goes and looks, ⓘ says what to look for, and ＋ Add photo takes evidence on the cards that want it.
    3. Press ＋ Include to push a card's notes and photos into the matching report section on the right. The report is built from what you include, so do it as you go rather than at the end.
    4. Sign off last, once you're happy with a card — it settles to one line, and the Signed off segment above counts them. Report sections carry their own separate Reviewed tick.

    Finish this list before exporting: the report on the right only shows what you've included here.

    Advanced options Several sites at once · import a findings file · let Claude run it · display & instructions

    Assess several sites at once

    Pick a list of sites and work them as a batch. Each opens into its own assessment and is saved separately, so you can finish them one at a time and fact-check the whole set at the end.

    Import a findings file

    Load a saved ess-findings/1 export, or a ess-findings-batch/1 file with a sites array (from resolve.py --batch … --template, filled in). A batch opens the picker bar above; a single file loads straight in. To paste an assistant's reply instead, use the box in step 3 — you don't need a file for that.

    Agent mode — let Claude run the whole assessment

    Instead of the copy-prompt/paste-back round trip in step 3, Claude can work through every source itself and fill the dashboard live. Needs your own Anthropic API key, which stays in this browser. Each run costs a few cents.

    Display options

    The alternate workflows, in full

    Copy prompt → paste back (the default). Step 3 copies one self-contained prompt describing this site and every source that applies to it. Any assistant with web access can work it; it replies with a single ess-findings/1 JSON object, which you paste into the box in step 3. Sources the reply leaves blank keep whatever result they already have, so running the auto-checks first is never wasted.

    Agent mode (bring your own key). Claude drives the same loop from inside this page using Anthropic's server-side web search & fetch, writing each result into the dashboard as it goes. Nothing is sent anywhere but api.anthropic.com, and no key is stored on any server — see docs/AGENT-MODE.md.

    The ess-collect skill. Running Claude Code in this repository? Ask it to "run an ESS for <site>" and the packaged skill produces the same JSON — with --batch for a whole list — which you bring back through Import a findings file above.

    Batches. Sites in a batch each keep their own findings, photos and report. Work one, export it, then pick the next from the tray above the workspace; Check all copies one fact- and consistency-check prompt covering the whole set.

    Statuses. Found and Nothing found are both real answers — the difference between "checked, and there is something" and "checked, and there is nothing". Search failed means the check couldn't be completed and Needs manual check means a human has to drive it, so both stay on the ⚠ Needs attention list until someone resolves them.

    Internal sources (the permits register, POPE / leasing SharePoint) are an operator action list. They show on the dashboard but their notes never reach the exported report. Hide them with Show internal / manual sources above.

    Client-side only — nothing you enter leaves your browser. Work is saved locally per site.
